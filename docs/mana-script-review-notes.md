# マナコーポレーション台本・確認修正メモ

10本すべての確認が終わるまで、各台本の修正内容をここへ記録する。
完了後、重複を整理して、しん・ゆうきの共通ルールと専用ルールへ一度に反映する。

## 1本目

- 「店舗全体を良くすることはできないんだ」ではなく、「店舗全体を良くすることはできない」と言い切る。
- 「周りを輝かせるために上に立つ」ではなく、「周りを輝かせる立場である必要がある」と役割として表現する。
- 「それを本気で喜べる人は強い」ではなく、「それを本気で喜べる人が、店長にふさわしいと思う」と、何にふさわしいのかを明示する。
- 確定している会社の特徴は「会社でいたい」ではなく、「会社です」と断定する。

## 2本目

- 「やるべきことが、初めて見えたんだ」ではなく、「やるべきことが、初めて見えた」と短く言い切る。
- 「最初から完璧な計画は必要ない」の前に、「夢は、最初は漠然としていてもいい」を入れ、結論へのつながりを自然にする。

## 3本目

- 「自分に問いかけるべきなんだ」ではなく、「自分に問いかける必要がある」と自然に言い切る。
- 退職を選んだスタッフへは、「外に出て、いろいろな会社や人に出会い、たくさんのことを学んでほしい」と前向きに伝える。
- 感謝を伝えることで、「退職したあとも、困ったときに連絡を取り合える関係であり続けられる」と、退職後にも関係を保てることを説明する。
- 最後は「戻りたいと思える場所をつくることも、経営者の大切な仕事なんだと思う」と、本人の考えとして締める。

## 4本目

- ゆうきの対談シリーズは、しんの語りのような断言調にしない。実際の対談らしく、「〜なんだよね」「〜と思っている」など、考えを話す柔らかい口調にする。
- 冒頭は「スタッフ同士の行き違いが起きたとき、これまではどうしていましたか？今考えると、一番反省していることは何ですか？」と、当時の対応と現在の反省を順番に聞く。
- 瀬川社長は、「当時は、本人たちの話を十分に聞く前に、自分の中で『原因はこれだ』と決めつけたんだよね」と会話らしく答える。
- 「早く指示を出せば、店舗の空気が悪くならずに済むと思っていたんですか？」では質問の意図がずれるため、「問題から逃げたい気持ちや、早く解決したい気持ちがあったんですか？」と動機を聞く。
- 返答では、「逃げたかったというより、早く収めることが解決だと思っていた」と、質問へ直接答えてから結果を説明する。
- カメラマンの「それなら」は削除し、「今は、どう向き合っていますか？」と自然につなぐ。
- ユーザー修正版では、「決めつけたんだよね」より「決めつけていたんだよね」を選び、当時続けていた考え方として語る。
- 「接客中の空気にも出てしまう」だけで終わらせず、「接客中の空気にも出てしまって、いいことがなかった」と、その経験から本人が感じた結果まで話す。
- ゆうきの瀬川社長は、一般論を断言する人ではなく、当時の自分の行動、起きた結果、今の反省を会話として振り返る。

## 5本目

- カメラマンの質問は、「会社はどう向き合いますか？」より「どう向き合いますか？」と余分な主語を省き、会話らしく聞く。
- ゆうきの瀬川社長は、「違うじゃん」「見える場合もあるからね」「確認するかな」「話し合う感じやね」のように、原稿を読んでいる敬語ではなく、普段の会話に近い口調で答える。
- 「その可能性はある」と懸念を否定せずに受け止めてから、一度退職したことだけでご縁まで否定しない理由を話す。
- 確認事項を並べたあと、「お互いが無理なく働けるかを話し合う感じやね」と、実際に取る行動を自然な言葉で説明する。
- 最後は「ご縁を大切にできる会社でいたい」という抽象的な願望ではなく、もう一度働きたいと思ってくれた人を「大切に迎え入れる」という具体的な行動で締める。
- ユーザー修正版の「向かい入れます」は、文脈上「迎え入れます」の意図として把握する。「思ってくれたらご縁を」は、「思ってくれたら、そのご縁を」または「思ってくれたご縁を」の意図として扱う。

## 6本目

- 冒頭は「技術以外に何を大切にしていますか？」という説明的な質問ではなく、「技術が上手いだけで、次も指名してもらえるものなんですか？」と、視聴者が感じる素朴な疑問から始める。
- 美容師スタッフは、前回の髪の悩みや仕上がりを覚え、次回来店時にその後を尋ねるという現場の接客を具体的に話す。
- 瀬川社長はスタッフと同じ説明を繰り返さず、「自分のことをちゃんと見てくれている」と感じてもらえることが信頼につながると、接客の意味を会話調で補足する。
- 「会話が得意ではない美容師もいますよね？」より、「会話が得意じゃない美容師だと難しくないですか？」と、反論として自然な聞き方にする。
- 美容師スタッフは「結局は、人対人なので」と、会話量ではなく相手を気にかける姿勢が大切だと説明する。
- 最後は理念を断言せず、「そう」「派手なことじゃなくても」と会話を受け、時間を守る、説明を忘れない、髪の状態を見るという小さな約束の積み重ねへつなげる。

## 7本目

- 「売上を目標にすること自体は大切だ」と断言せず、「大切だけど」「違うのは、その売上をどうつくるかだよね」と、瀬川社長が相手へ語りかける口調にする。
- 「単価だけを上げる」という抽象表現ではなく、「物販等で単価だけを上げる」と、美容室で実際に起こる行動を示す。
- 売上を否定せず、「短期的にはプラス」と一度認めてから、お客様の信頼を失えば次の来店につながらないと説明する。
- 最後は「今はそう考えている」と断言調で閉じず、「今はそう考えているね」と、本人の現在の考えを会話として話す。
- ユーザー修正版の「短期的にはプラスだけどただ」は、「短期的にはプラスだけど」のあとに続ける意図として把握する。「どうつくるかだよね」の次に単独で置かれた句点は、前文末の句点として扱う。

## 8本目

- 冒頭は「何が違いますか？」という抽象的な比較ではなく、「どういう行動が違いますか？」と聞き、回答が具体的な行動になるようにする。
- 瀬川社長は「大切だ」「成長できない」と断言せず、「大切だと思う」「成長できないね」と、考えを会話として伝える。
- 後輩へ声をかける個人の心がけだけで終わらせず、会社として勤務時間内に練習する時間を設けていることまで話し、会社が成長を支える仕組みを示す。
- カメラマンは「聞いていて、一人だけではなく、店舗全体で成長することが必要なんですね」と、直前の回答を聞いて理解した流れで次へ進む。
- 最後は「そう」と受けてから、後輩の成長が店舗全体への信頼につながることを話す。
- ユーザー修正版の「練習をする時間も儲けている」は「練習する時間も設けている」の意図として把握する。「勤務時間で」は「勤務時間内に」、「そう後輩」は「そう。後輩」の意図として扱う。

## 9本目

- 冒頭は「結婚など、将来の生活を考え始めたとき」と対象を限定せず、「入社前はどんな不安がありましたか？」と、本人の経験を広く聞く。
- 美容師スタッフは、出来高制サロンにも興味があったことを先に話したうえで、毎月の収入、社会保険、生活が変わったあとも働き続けられるかという現実的な不安を説明する。出来高制を一方的に否定せず、本人が比較して迷った流れにする。
- 「マナ」ではなく「マナコーポレーション」と正式名称で質問する。
- 美容師スタッフは、出来高制ではないこと、毎月の収入が安定しやすいこと、直接雇用で社会保険があることを、将来の生活を具体的に考えられるようになった理由として話す。
- 瀬川社長は「好きという気持ちだけで頑張らせてはいけない」と、会社が働き続けられる土台を整える必要性を話す。ただし、ユーザー修正版の「それが安心だと思いました」は、文脈上「それが安心につながると思いました」または「その環境が安心につながると思いました」の意図として扱い、主語と意味が通る日本語に整える。
- 美容師スタッフは、生活を見通せることで、お客様への接客や技術練習に集中できるようになり、長く美容師を続ける未来を描けるようになったと、生活面と仕事面の変化をつなげて話す。
- ゆうきの美容師スタッフの回答は、「変わった」と強く始めても、最後まで断言調でそろえる必要はない。「未来まで描けます」のように、本人が自然に話す丁寧な語尾を使ってよい。
- 最後は「これからもつくっていく」という抽象的な決意ではなく、「安心して続けられる環境を提供するのがマナコーポレーションです」と、会社が実際に提供する役割として締める。
- ユーザー修正版の「出来高制サロンも興味がありましたが」は「出来高制サロンにも興味がありましたが」、「環境を、提供する」は読点を外して「環境を提供する」の意図として扱う。

## 10本目

- 冒頭はカメラマンの説明的な質問から始めず、美容師スタッフ本人の「売上によって毎月の収入が変わると、家賃や生活費を払ったあと、手元にいくら残るのか分からないことが不安でした」という実体験から入る。毎回同じ質疑応答の始まり方にしない。
- 出来高制を一方的に否定せず、カメラマンが「売上が上がれば、出来高制の方が合う人もいますよね？」と別の見方を示し、美容師スタッフが「そういう人もいると思います」と認めてから、自分には何が合っていたかを話す。
- 美容師スタッフの不安は、収入が低いという決めつけではなく、「技術を身につける時期に、収入の心配まで抱えたくなかった」という本人の優先順位として説明する。
- 瀬川社長は「働き方に一つの正解があるわけではありません」と選択肢を尊重したうえで、マナコーポレーションは出来高制ではなく、直接雇用で毎月の収入が安定しやすい環境を整えているという確認済みの事実を伝える。
- カメラマンは「その環境で何が変わりましたか？」のように結論を誘導せず、「働いてみてどうでしたか？」と本人が経験を答えやすい自然な質問をする。
- 美容師スタッフは、毎月の売上だけに追われず、身につけたい技術、なりたい美容師像、長くどう働きたいかを考えやすくなったと、働いたあとの具体的な変化を話す。
- 最後は会社の制度だけを繰り返さず、「生活への不安を減らし、お客様に向き合いながら成長できる環境をつくることが、人を大切にする経営」という社長の価値観へつなげる。
- ゆうきの対談は必ずカメラマンから始める必要はない。美容師スタッフの実体験から始める、カメラマンが途中から別の見方を出す、社長が会社の考えを補足するなど、内容に合う順番へ変える。
